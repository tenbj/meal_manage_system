# 减肥餐管理后台离线原型

打开 `05_减脂双餐后台服务层原型.html` 即可使用。当前版本是离线高保真原型，数据保存在浏览器 `localStorage` 中，可模拟新增、编辑、删除、生成、复制和导出图片等流程。

## 原型边界

- 暂无真实数据库、服务端 API 或多人权限。
- 不录入真实客户隐私数据；请使用样例或脱敏数据测试。
- 清空浏览器缓存或换浏览器会丢失本地模拟数据。
- 后续接数据库时，可按 `assets/admin.js` 中的九类数据表替换存储层：客户表、服务订单表、菜品表、食谱表、每日出餐表、反馈表、标签表、配送表、总结海报表。

## 建议验收路径

1. 首页看板查看今日待处理事项。
2. 新增客户档案并记录体重。
3. 给客户新增 6 天体验服务或 28 天正式服务。
4. 在菜品管理里新增或标记今日不可用菜品。
5. 在食谱管理里生成当天午餐、晚餐食谱，并做客户单独替换。
6. 在每日出餐里生成午餐和晚餐出餐表，调整克重并确认。
7. 录入客户反馈，观察第二天克重建议变化。
8. 在标签与配送里分午餐、晚餐生成标签和配送清单。
9. 在服务总结海报页选择已结束服务，生成并导出总结图片。
