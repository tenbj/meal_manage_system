餐食管理系统 · Docker 部署架构

生成于 2026-10-13 · Node/Express 保留业务实现，内置 MCP 复用 API。

入口与权限

用户可自行注册，密码加盐scrypt摘要；浏览器使用7天可撤销HttpOnly会话。API/MCP使用账号私有的只读/读写Bearer凭据摘要，MCP保留调用者身份。Docker 默认仅绑定回环。支持显式 HTTP/HTTPS 多入口白名单；HTTPS Cookie 带 Secure，HTTP 独立登录同一账号。云端 Caddy → FRP → 应用容器。

数据边界

merchant_workspace.payload 是新版业务事实源。旧九表只在首次初始化导入，不与新版自动同步。api_requests 保存幂等响应和来源。merchant_integrations 按owner_id保存薄荷密钥，不进入工作台JSON、不通过接口回显；它不是加密存储，数据库及备份必须私密保护。图中的分层箭头表示处理层依赖，不代表每张卡逐一直接调用。

部署与恢复

应用单容器；可接已有 MySQL 或独立 MySQL 容器。静态文件 COPY 入镜像；正式可复用既有数据库；密钥随商家库备份。原 .runtime / 环境配置只有显式验证迁移后进入数据库，已存数据库配置不会被覆盖。增量迁移独立执行；不自动种子或清库。
